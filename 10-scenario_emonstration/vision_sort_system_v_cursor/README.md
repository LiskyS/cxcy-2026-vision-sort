# vision_sort_system_v_cursor

电子元器件视觉分拣系统数字孪生（Vue3 + Three.js + Element Plus）。

## 功能

- 三维动画展示四段流程：**送货 → 识别 → 分拣 → 取货**
- **开始 / 暂停 / 停止** 控制
- **实时统计面板（右侧栏最上方）**：累计数量、按类型数量、最新识别/分拣类型与位置
- 分拣采用**机械臂抓取-放置**动作（非瞬移）

## 运行

```bash
cd vision_sort_system_v_cursor
npm install
npm run dev
```

## 构建

```bash
npm run build
```
